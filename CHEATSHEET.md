# Speak37 cheat sheet

Speech, played musically. A pad is a sentence; every key speaks its next word at the key's pitch.

```
 KNOBS   K1 MASTER   K2 PAGE     K3 VOICE    K4 BANK          (the screen's knob block: the same order,
         K5..K8 the page's four                                the knob turned last framed, each named K1..K8)
 PAGES   PLAY     TEMPO    SPEED     INTONE    ROOT
         VOICE    FORMANT  BREATH    LOFI      METAL
         ENVELOPE ATTACK   RELEASE   HOLD      GLIDE
         MOD      VIB RATE VIB DEPTH WOB RATE  WOB DEPTH
         DELAY    TYPE     TIME      REPEATS   MIX
         SPACE    REVERB   SIZE      SPREAD    TONE
         RHYTHM   TEMPO    DRUMS     SWING     GROOVE         (SEQ)
         SETUP    BEND     CHORD     VELO      TRS OUT        (GLOBE)
 FADERS  F1 SPEED    F2 FORMANT  F3 DELAY MIX  F4 REVERB
 PADS    the bank's 16 sentences (top 1..8, bottom 9..16): dim 10 %, in use 45 %, speaking 100 %
         USER bank: an empty pad faint (LONG CLICK TO RECORD); held 0.6 s: the editor
         RHYTHM: the 16 grooves (tap: start, on the bar while PLAY runs; the playing one again: stop)
         PATCH held 0.6 s: the 16 memories (tap: load, hold 1 s: save); PATCH tapped: MOPE
 EDITOR  keys: a letter (A..Z from the lowest)   K5, < >: the word list
         pads  ADD   PICK  NEXT  DEL LTR  DEL WORD  PREVIEW  EN/DE  -
               -     -     -     -        -         -        CANCEL OK
```

| Button | Function |
|---|---|
| < > | the word before / next |
| SEQ PLAY | PLAY: the sentence by itself in time; the keys choose its pitch (a chord: all its notes); again: stop |
| SEQ REC | back to the first word |
| SEQ | RHYTHM: the page, the pads the grooves |
| PARA | FILL (the next bar's last beat) |
| SCALE | the keys: SENTENCE, LETTERS (A..Z, ZERO..NINE), KIT (16 hits, the pads too) |
| PATCH | tap: MOPE on / off; held 0.6 s: the memories |
| NOTE REPEAT | REPEAT: the same word every key |
| CHORD | keys together speak one word (on / off) |
| ARP | ONE SHOT / GATE / HOLD / LOOP |
| FX | DELAY page, again SPACE |
| GLOBE | SETUP |
| KNOB BANK / FADER BANK | next / previous page |
| OCTAVE- / + | the octave; both 5 s: update mode |

Voices: CLASSIC, VINTAGE (the chip's chirp), DEEP, CHILD, WHISPER, ROBOT, LAB AI (clean, semitone-stepped),
GIANT, CHOIR (three voices a note). Banks: SONGS (sung words), CHURCH (sung syllables: hold a key, the vowel holds), ROMANTIC,
MANTRAS, PERCUSSION, DAD JOKES 1, DAD JOKES 2, CRINGE, ROBOT, LAB AI, SPELLING, NUMBERS, DEUTSCH, FRANCAIS,
ESPANOL, ITALIANO, NEDERLANDS, SVENSKA, ZHONGWEN, NIHONGO, USER. Grooves: BOSSA NOVA, SAMBA, REGGAE DUB, DUB HOUSE,
HOUSE, TECHNO, BOOM BAP, TRAP, DRUM AND BASS, FUNK, DISCO, ROCK, SHUFFLE, WALTZ, AFROBEAT, ELECTRO.

MOPE (PATCH; FM-1: EDIT held 0.6 s): every control only talks to it; keys a tone; it comments after a phrase
and on every control; pads: top row praise, 9..12 poke, 13..16 a joke; now and then LIGHTS, DARK, ASK (use
the control it names), GAME (hit the moving light); bored enough it plays itself (any key stops it). FM-1:
REC praise, PLAY poke, SEQ a joke. PATCH again: everything as before.

FM-1: SELECT page (RHYTHM: KNOB 4 the groove), ALGORITHM voice, PRESETS sentence (all banks), KNOB 1..4 the page's
four; SAVE held 1 s saves, SAVE + PRESETS picks a memory; SEL HOME ENV LFO FX pages; GLO SETUP; EDIT LETTERS; ARP /
SEQ word back / next; PLAY PLAY; REC first word, held 0.6 s on a USER pad: the editor (REC ADD, HOME PICK, ENV
NEXT, LFO DEL LTR, FX DEL WORD, PLAY PREVIEW, EDIT EN/DE, GLO CANCEL, SAVE OK; KNOB 1, ARP / SEQ the list).
